# Chrome 웹 스토어 비공개 게시 안내 (지인 2~3명용)

## 준비물 (이 폴더에 있음)
- 업로드 파일: `release/uwts-lyrics-0.1.0.zip` (`npm run pack`으로 다시 만들 수 있어요)
- 스토어 아이콘: `store/icon-512.png` (128×128로 줄여 올려도 돼요: `public/icons/icon128.png`)
- 스크린샷: `store/screenshot-1280x800.png`
- 개인정보처리방침: `store/privacy.html` (공개 주소가 필요해요. 아래 5번 참고)

## 1. 개발자 계정 만들기 (처음 한 번)
1. https://chrome.google.com/webstore/devconsole 접속, 본인 Google 계정으로 로그인
2. 개발자 약관 동의 → 등록비 5달러 결제 (한 번만)

## 2. 새 항목 올리기
1. "새 항목" → zip 업로드
2. **스토어 등록정보** 탭
   - 설명: 아래 "소개 문구" 붙여넣기
   - 카테고리: 엔터테인먼트, 언어: 한국어
   - 아이콘·스크린샷 업로드

## 3. 개인정보 보호 탭 (아래 문구 그대로 붙여넣기)
- **단일 목적**: YouTube 음악 영상 옆에 재생 위치에 맞춰 따라가는 가사를 보여 줍니다.
- **storage**: 찾은 가사 캐시, 사용자가 고른 가사, 싱크 맞춘 기록, 패널 설정을 기기에 저장합니다.
- **declarativeNetRequestWithHostAccess**: 가사 서비스(music.163.com) 요청에서 브라우저가 붙이는 Origin/Referer 헤더를 빼야 정상 검색 결과가 오기 때문에 사용합니다. 다른 사이트 요청은 건드리지 않습니다.
- **호스트 권한**
  - youtube.com: 재생 중인 영상 옆에 가사 패널을 표시하고 영상 제목·길이를 읽습니다.
  - i.ytimg.com: 영상 썸네일 색으로 패널 배경색을 만듭니다.
  - lrclib.net, music.163.com: 곡 가사를 검색합니다.
  - (선택) bugs.co.kr, genie.co.kr, melon.com: 사용자가 설정에서 켠 경우에만 국내 가사를 검색합니다.
- **원격 코드 사용**: 아니요
- **데이터 사용**: "웹사이트 콘텐츠"에 체크 (노래 제목·가수 검색어를 가사 서비스로 보냄). 판매·광고·신용평가 용도 아님 3개 모두 체크
- **개인정보처리방침 URL**: 5번에서 만든 주소

## 4. 배포 탭: 비공개로 설정
1. 공개 범위(Visibility) → **비공개(Private)**
2. **신뢰할 수 있는 테스터(Trusted testers)** 에 친구 Gmail 주소 2~3개 입력 (쉼표로 구분)
3. "검토를 위해 제출" → 보통 며칠 안에 승인돼요

## 5. 개인정보처리방침 공개 주소 만들기
`store/privacy.html` 내용을 누구나 볼 수 있는 곳에 올려야 해요. 예: 노션 페이지를 "웹에 공개", 또는 공개 GitHub Gist.
(원하시면 제가 올려 드릴게요. 공개 위치에 게시하는 거라 먼저 확인받을게요.)

## 6. 친구에게 전달
승인 후 대시보드의 스토어 링크를 친구에게 보내면 돼요. 등록된 Gmail로 Chrome에 로그인한 상태에서 열고 "Chrome에 추가"를 누르면 끝이에요.

## 업데이트할 때
1. `public/manifest.json`의 `version`을 올려요 (예: 0.1.0 → 0.1.1)
2. `npm run pack` → 대시보드 "패키지" 탭에서 새 zip 업로드 → 제출
3. 승인되면 친구 브라우저에 자동으로 업데이트돼요

## 소개 문구 (스토어 설명에 붙여넣기)
YouTube 음악 영상 오른쪽에 노래방처럼 따라가는 가사를 보여 줘요.

- 재생 위치에 맞춰 지금 부르는 줄이 하이라이트되고 채워져요
- 여러 곡이 이어지는 플레이리스트 영상도 곡마다 가사를 바꿔 보여 줘요
- 가사가 어긋나면 "싱크 맞추기"를 누르고 지금 부르는 줄을 한 번 눌러 맞출 수 있어요
- 다른 노래가 잡히면 직접 검색해서 고를 수 있어요
- 영상 썸네일 색에 맞춰 배경 색이 바뀌어요
