## 📥 처음 설치하기

> GitHub 계정이 있어야 받을 수 있어요. 초대 메일의 **Accept invitation**을 먼저 눌러 주세요.

1. 아래 **Assets**에서 `uwts-lyrics-x.y.z.zip`을 받아요.
2. 압축을 풀면 나오는 **`uwts-lyrics` 폴더**를 지우지 않을 곳(예: 문서 폴더)에 옮겨 둬요.
3. 주소창에 `chrome://extensions`를 입력해요.
   - Edge는 `edge://extensions`, 웨일은 `whale://extensions`
4. 오른쪽 위 **개발자 모드**를 켜요.
5. **압축해제된 확장 프로그램을 로드합니다** → `uwts-lyrics` 폴더를 선택해요.
6. 유튜브에서 노래 영상을 열면 오른쪽에 가사가 나와요.
   - **가사 소스 권한 허용** 버튼이 보이면 한 번 눌러 주세요.

> ⚠️ `uwts-lyrics` 폴더를 지우면 확장 프로그램도 사라져요.

## 🔄 업데이트하기

패널 위에 **새 버전 받기**가 뜨면:

1. 눌러서 zip을 받아요.
2. 압축을 풀어 원래 `uwts-lyrics` 폴더에 **덮어쓰기**해요.
3. 유튜브를 새로고침하면 끝이에요.

## 🎤 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 그 부분으로 이동 | 가사 줄 클릭 |
| 다른 가사 둘러보기 | 패널에서 스크롤 (마우스를 빼면 다시 따라가요) |
| 싱크가 어긋날 때 | 패널에 마우스 올리기 → **싱크 맞추기** → 지금 부르는 줄 클릭 |
| 다른 노래가 잡혔을 때 | 🔍 돋보기로 검색해서 고르기 |
