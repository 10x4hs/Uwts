Uwts Lyrics 설치 방법 (Chrome · Edge · Whale · Brave)
=====================================================
유튜브 뮤직비디오 오른쪽에 노래방처럼 따라가는 가사를 보여 주는 확장 프로그램이에요.

[처음 한 번]
1. GitHub 초대 메일에서 "Accept invitation"을 눌러요. (GitHub 계정 필요)
2. https://github.com/10x4hs/Uwts/releases 에서 맨 위 버전의
   uwts-lyrics-x.y.z.zip 을 받아 압축을 풀어요.
   → 나오는 "uwts-lyrics" 폴더를 지우지 않을 곳(예: 문서 폴더)에 두세요.
3. 주소창에 chrome://extensions 입력 (Edge: edge://extensions, 웨일: whale://extensions)
4. 오른쪽 위 "개발자 모드" 켜기 → "압축해제된 확장 프로그램을 로드합니다" → uwts-lyrics 폴더 선택
5. 유튜브 노래 영상을 열면 오른쪽에 가사 패널이 나와요.
   "가사 소스 권한 허용" 버튼이 보이면 한 번 눌러 허용해 주세요.

[업데이트] (브라우저에서 GitHub에 로그인돼 있으면 패널에 알림이 떠요)
1. 패널의 "새 버전 받기"를 눌러 zip을 받아요.
2. 압축을 풀어 원래 uwts-lyrics 폴더에 덮어써요.
3. 유튜브 탭을 새로고침하면 끝이에요. (확장 프로그램이 새 버전으로 알아서 다시 시작해요)

[쓰는 법]
- 가사 줄을 누르면 그 부분으로 이동해요.
- 가사가 어긋나면 패널에 마우스를 올려 "싱크 맞추기" → 지금 부르는 줄을 눌러요.
- 다른 노래가 잡히면 돋보기로 직접 검색해서 골라요.

[알아 두기]
- 개인적으로 쓰라고 나눠 드리는 거예요. 다른 사람에게 다시 나눠 주거나 인터넷에 올리지 말아 주세요.
