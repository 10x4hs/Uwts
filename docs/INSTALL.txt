Uwts Lyrics 설치 방법 (Chrome · Edge · Whale · Brave)
=====================================================

유튜브 뮤직비디오 오른쪽에 노래방처럼 따라가는 가사를 보여 주는 확장 프로그램이에요.

[처음 설치]
1. 받은 zip 파일의 압축을 풀어요.
   → 나오는 "uwts-lyrics" 폴더를 지우지 않을 곳(예: 문서 폴더)에 두세요.
     폴더를 지우거나 옮기면 확장 프로그램이 꺼져요.
2. 주소창에 chrome://extensions 를 입력해요.
   (Edge는 edge://extensions, 웨일은 whale://extensions)
3. 오른쪽 위 "개발자 모드"를 켜요.
4. "압축해제된 확장 프로그램을 로드합니다"를 누르고 uwts-lyrics 폴더를 선택해요.
5. 유튜브에서 노래 영상을 열면 오른쪽에 가사 패널이 나와요.
   패널 위에 "가사 소스 권한 허용" 버튼이 보이면 한 번 눌러 허용해 주세요.

[업데이트]
1. 새 zip을 받으면 같은 자리에 압축을 풀어 덮어써요.
2. chrome://extensions 에서 Uwts Lyrics의 ↻(새로고침)을 눌러요.
3. 열려 있는 유튜브 탭도 새로고침해요.
   (같은 폴더 위치를 쓰면 싱크 맞춘 기록과 설정이 그대로 남아요.)

[쓰는 법]
- 가사 줄을 누르면 그 부분으로 이동해요.
- 가사가 노래보다 빠르거나 느리면 "싱크 맞추기"를 누르고, 지금 부르는 줄을 눌러 주세요.
- 다른 노래 가사가 나오면 돋보기 버튼으로 직접 검색해서 고를 수 있어요.

[알아 두기]
- 개인적으로 쓰라고 나눠 드리는 거예요. 다른 사람에게 다시 나눠 주거나 인터넷에 올리지 말아 주세요.
- 브라우저가 "개발자 모드 확장 프로그램" 경고를 띄우면 그대로 유지(취소)를 누르면 돼요.
